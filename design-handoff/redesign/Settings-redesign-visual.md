# ТЗ на реализацию: раздел «Настройки» (MACRO CRM, редизайн)

## 1. Обзор

Полный редизайн модуля **«Настройки»** MACRO CRM. Экран построен как двухколоночный layout: левый рельс-навигация по разделам + правая рабочая область с контентом выбранного раздела. Поддерживаются светлая и тёмная (navy) темы.

Разделы:
- **Аккаунт → Профиль** (4 вкладки: Профиль, Безопасность, Внешний вид, Язык)
- **Интеграции → Каналы связи**
- **Справочники → Справочники** (11 подвкладок-справочников) + ссылка на «Воронку продаж» (внешний экран)
- **Система → Пользователи, Доступ и оргструктура, Журнал автоматизаций, Сброс системы**

## 2. О файлах в этом бандле

Файлы в папке `design/` — это **дизайн-референс, сделанный на HTML/React (через Babel-standalone в браузере)**. Это прототип, показывающий финальный внешний вид и поведение, **а не продакшн-код для копирования один-в-один**.

Задача — **воспроизвести эти экраны в существующем окружении вашего кодовой базы** (React/Vue/Angular и т.д.), используя её сложившиеся паттерны, компоненты и библиотеки. Наш CRM использует **PrimeReact / PrimeIcons** и набор дизайн-токенов `--mg-*` (см. `tokens/`) — реализацию нужно вести на этих же токенах и, где возможно, на готовых компонентах PrimeReact.

Прототип рендерится standalone: откройте `design/settings.html` в браузере (нужен интернет для CDN React/Babel/PrimeIcons). Токены и глобальные стили лежат рядом (`styles.css` + `tokens/`), путь уже прописан.

## 3. Фиделити

**High-fidelity (hi-fi).** Цвета, типографика, отступы, радиусы, тени, состояния и микроповедение — финальные. Верстать пиксель-в-пиксель на токенах `--mg-*`. Все размеры в этом ТЗ указаны в `px`, если не оговорено иное.

## 4. Дизайн-токены

Все значения берутся из CSS-переменных (`tokens/`). **Не хардкодить hex — использовать переменные.**

### Цвета — бренд (navy)
| Токен | Светлая | Назначение |
|---|---|---|
| `--mg-primary-900` | `#172747` | Основной бренд-навы: primary-кнопки, активные состояния, акцентный текст |
| `--mg-primary-800` | `#1f2f5a` | Второй стоп градиента героя |
| `--mg-primary-100` | `#e3e8f3` | Фон иконок-плашек, активный пункт навигации |
| `--mg-primary-50` | `#f5f7fb` | — |

> В **тёмной теме** бренд ремапится (`tokens/dark.css`): `--mg-primary-900 → #4C7DF0`, `--mg-primary-800 → #6E99FF`. Поэтому нигде не пишем `#172747` напрямую — только `var(--mg-primary-900)`.

### Цвета — статусы
| Токен | Значение (light) | Назначение |
|---|---|---|
| `--mg-status-success-bg` | `#dcfadc` (green-100) | Фон тега «Подключено / Успешно» |
| `--mg-status-success-text` | `#2b6b38` (green-900) | Текст успеха, «2FA включена» |
| `--mg-status-danger-bg` | `#fff5f4` (red-50) | Фон баннера-предупреждения |
| `--mg-status-danger-text` | `#e61c14` (red-700) | Текст/бордер опасных действий, danger-пункт навигации |
| `--mg-status-danger-solid` | `#FF5A44` (red-500) | Заливка кнопки необратимого действия |

### Локальные surface-переменные (объявлены в `settings.html`, `.surface`)
Экран задаёт свою палитру нейтралей поверх токенов — при переносе замапьте на аналоги вашей системы:
```
--c-page:#F1F2F3   фон рабочей области
--c-card:#FFFFFF   карточки, рельс, шапка
--c-border:#E3E4E6 основные разделители
--c-border2:#D5D6D8 бордеры инпутов/сегментов
--c-text:#272829   основной текст
--c-text2:#616263  вторичный текст, лейблы
--c-muted:#7E7F82  подписи, плейсхолдеры
--c-hover:#F9FAFB  hover-фон, «мягкие» плашки
--c-muted2:#ECEDEF архивные аватары
--sw-off:#C3C8D2   выключенный тумблер (тёмная: #455778)
```
Тёмная тема включается классом `.surface.dark` (навигационные navy-нейтрали приходят из `tokens/dark.css`).

### Радиусы
`--mg-radius-sm: 4px` (инпут/тег/бейдж) · `--mg-radius-md: 6px` (кнопка/карточка/дропдаун — дефолт) · `--mg-radius-lg: 8px` (диалог/крупная карточка) · `--mg-radius-xl: 12px` (аватар/иконка-плашка).

### Тени
`--mg-shadow-sm: 0 1px 2px rgba(0,0,0,.05)` (карточки) · `--mg-shadow-lg` (модалки). В тёмной теме тени глубже (см. `dark.css`).

### Типографика
Шрифт: `--mg-font-sans: Inter, -apple-system, …`. Веса: 500 (обычный текст/пункты), 600 (заголовки/лейблы/акценты), 700 (числовые бейджи, коды).
Ключевые размеры: h1 модуля 20/600 · h2 раздела 18–20/600 · заголовок карточки 15/600 · body 13.5–14 · подписи 12.5–13 · мелкие теги/оверлайны 11/600 uppercase (`letter-spacing:.07em`).

### Иконки
**PrimeIcons 7** (`pi pi-*`). Используемые: `pi-cog, pi-user, pi-share-alt, pi-folder-open, pi-sliders-h, pi-users, pi-shield, pi-clock, pi-refresh, pi-search, pi-external-link, pi-key, pi-lock, pi-desktop, pi-mobile, pi-sun, pi-moon, pi-check, pi-check-circle, pi-circle, pi-camera, pi-cloud-upload, pi-eye, pi-qrcode, pi-copy, pi-telegram, pi-envelope, pi-whatsapp, pi-link, pi-unlink, pi-globe, pi-verified, pi-exclamation-triangle, pi-times, pi-chevron-up/-down`.

## 5. Общий layout

```
┌──────────────────────────────────────────────────────────┐
│ HEADER  [cog] Настройки                    [☾/☀ тема]      │  h≈68, bg card, borderBottom
├───────────────┬──────────────────────────────────────────┤
│  NAV (264px)  │  DETAIL (flex:1, overflowY:auto, pad 24)   │
│  поиск        │   maxWidth контента:                       │
│  группы+пункты│   680px (обычно) / 1080px (Пользователи,    │
│  active: navy │              Доступ)  · margin:0 auto       │
│  инд. слева   │                                            │
└───────────────┴──────────────────────────────────────────┘
```

- **Header** (`display:flex; gap:14; padding:15px 24px`): плашка-иконка 38×38 (`--mg-primary-100`, `pi-cog` navy) + `<h1>Настройки` (20/600, `flex:1`) + кнопка-переключатель темы (ghost, 38×38, иконка `pi-sun`/`pi-moon`).
- **Nav** (`width:264; flex-shrink:0; overflowY:auto; bg card; borderInlineEnd`): сверху поле поиска (h36, бордер `--c-border2`, фон `--c-page`, иконка `pi-search`) фильтрует пункты по подстроке в лейбле. Далее группы.
  - **Заголовок группы**: 11/600 uppercase, `letter-spacing:.07em`, `--c-muted`, `padding:12px 18px 6px`.
  - **Пункт**: кнопка `width:calc(100% - 16px); margin:2px 8px; padding:9px 12px; gap:11; borderRadius:md`. Иконка 14px (`opacity:.8`, ширина 16) + лейбл (13, ellipsis) + опц. `meta` (число справа, 11/700 muted) + опц. `pi-external-link` (для «Воронки продаж»).
  - **Active**: `bg --mg-primary-100`, текст `--mg-primary-900` 600, слева индикатор `box-shadow: inset 3px 0 0 var(--mg-primary-900)`.
  - **Danger-пункт** («Сброс системы») в неактивном состоянии — текст `--mg-status-danger-text`.
- Контейнер контента ограничен по ширине и центрирован; всё, что шире (таблицы), — со своим горизонтальным скроллом (см. §11).

## 6. Общие компоненты

- **Кнопки** (`btn(kind)`): база `h38; padding:0 15px; gap:7; radius:md; 13/600`.
  - `primary` — bg `--mg-primary-900`, текст #fff.
  - `ghost` — bg card, бордер `--c-border2`, текст `--c-text2`.
  - `danger` (для «Отключить/Удалить») — ghost + текст `--mg-status-danger-text`, бордер `--mg-status-danger-border`.
- **Switch/тумблер**: 44×24, radius 999. On → трек `--mg-primary-900`, кружок 18×18 сдвинут вправо; Off → трек `--sw-off`. Transition .18s.
- **Field/инпут**: лейбл 13/600 `--c-text2` (mb7) + `<input>` h40, `padding:0 13px`, radius md, бордер `--mg-input-border`. Disabled — фон `--mg-input-disabled-bg`, текст muted.
- **Card**: bg card, бордер `--c-border`, radius lg, shadow-sm, `padding:20px 22px`, mb16. Опц. заголовок 15/600 + описание 13 muted.
- **SettingRow**: строка `h≈15px 0`, borderBottom-разделитель; слева опц. плашка-иконка 34×34 (`--mg-primary-100`), в центре title 14/600 + sub 12.5 muted, справа — контрол.
- **Modal**: оверлей `rgba(9,16,32,.55)`, по центру; карточка `maxWidth` задаётся (400–544), radius lg, shadow-lg. Шапка (иконка + заголовок 16/600 + `pi-times`), тело `padding:20`, футер с кнопками. Закрытие по клику на оверлей и на крестик.
- **Tag/бейдж**: `11/600; padding:3px 9px; radius:999`. Варианты: success (зелёный триад), «Скоро» (`--c-hover`/muted), navy (в шапке — полупрозрачный белый).
- **Toast**: фикс. снизу-справа, `minWidth:260; maxWidth:360`, иконка `pi-check-circle` + текст, анимация `toastIn` (fade+translateY 8px).

## 7. Раздел «Профиль»

**Hero-карточка** (radius lg, overflow hidden):
- Верх — градиент `linear-gradient(100deg, var(--mg-primary-900), var(--mg-primary-800))`, `padding:22px 24px`. Аватар 72×72 (круглый, `rgba(255,255,255,.18)`, бордер 3px `rgba(255,255,255,.5)`, инициалы «БЯ» 26/600 белые) + имя 20/600 #fff + бейдж роли (полупроз. белый) + email `rgba(255,255,255,.82)` + справа кнопка «Изменить фото» (полупрозрачная белая, открывает модалку фото).
- Низ — мета-строка (`padding:14px 24px; gap:24; flex-wrap`): «Вход: сегодня 09:12» (`pi-clock`), «2FA включена» (`pi-verified`, success-текст), «Русский» (`pi-globe`). Каждый пункт `white-space:nowrap` — переносится целиком, не рвётся.

**Подвкладки** (таб-бар, borderBottom, активная — navy текст + подчёркивание 2px): Профиль · Безопасность · Внешний вид · Язык.

- **Профиль**: Card «Личные данные» — попарные поля (Имя/Фамилия, Телефон/Email[disabled]), Должность[disabled]; снизу справа «Отмена» (ghost) + «Сохранить» (primary, `pi-check`).

- **Внешний вид**: Card с тремя блоками —
  - **Тема**: 2 крупные карточки-превью (Светлая/Тёмная), выбранная — бордер 2px navy + `pi-check-circle` в углу; переключает тему всего экрана.
  - **Акцент**: 4 круглых свотча (`#172747, #2B4987, #312e81, #0f4d3a`), выбранный — двойное кольцо + `pi-check`.
  - **Плотность интерфейса**: сегмент-контрол Компактная/Просторная (пилюля на `--mg-surface-muted`, активная — белая с shadow-sm).
- **Язык**: Card, список RU/EN/AR — плашка-код 30×30 + название + радио-кружок (выбранный navy).

**Модалки профиля**: «Изменить фото» (аватар + dropzone `pi-cloud-upload`, футер Удалить/Отмена/Сохранить), «Смена пароля» (3 поля с `pi-eye` + чек-лист требований), «2FA» (QR `pi-qrcode` + ручной ключ моно + 6 ячеек кода), «Активные сессии» (список устройств, у текущей бейдж «Текущая», у прочих «Завершить»; футер «Завершить все остальные»).

### 10.2 Доступ и оргструктура (`design/access-section.jsx`, `maxWidth:1080`)

- **Роли и права**: инфо-баннер «Роль admin всегда получает все права…». Группы прав (CRM, Продажи, …) со счётчиком; таблица: строка = право (название + код `crm.view` моно) × колонки-роли (Админ/Директор/Юрист/Менеджер) с чекбоксами. Права админа задизейблены (всегда вкл).
- **Видимость**: баннер-предупреждение; таблица Роль × дропдаун «Видимость записей» (Все / Отдел (+подотделы) / Только свои и т.п.).

### 10.3 Журнал автоматизаций (`design/system-section.jsx` → `AutomationsTab`, `maxWidth:680`)
Заголовок + описание «История срабатывания правил … за последние 24 часа».
Тулбар: поиск + **сегмент-фильтр по статусу со счётчиками**: Все 10 · Успешно 7 · Ошибка 2 · Пропущено 1 + кнопка «Обновить» (`pi-refresh`).
**Таблица** (в обёртке `overflowX:auto`, `minWidth:860`): Время (моно, `02.07 · 09:41`) · Автоматизация · Триггер (тег с иконкой) · Объект (ссылка `Сделка #10485`) · Действие · Статус (тег: Успешно=зелёный, Ошибка=красный, Пропущено=нейтральный). 10 записей.

### 10.4 Сброс системы (`design/system-section.jsx` → `ResetTab`, `maxWidth:680`)
Заголовок + описание «Выборочное удаление данных…». В отличие от полного wipe — **выбор категорий галочками**.
- **Красный баннер** (`--mg-status-danger-bg`, `pi-exclamation-triangle`): «Операция необратима…».
- **Мастер-строка** «Выбрать всё» (чекбокс с indeterminate-состоянием) + справа счётчик «Выбрано: N из 9» (`white-space:nowrap`).
- **9 категорий** (Сделки, Контакты, Компании, Задачи и активности, Документы, Финансы, Журналы, Правила автоматизаций, Справочники): чекбокс + иконка + название + описание + число записей (тег справа). Выбранная строка подсвечивается. Клик по чекбоксу не должен всплывать на клик строки (иначе двойной тоггл).
- **Блок подтверждения**: инпут — ввод слова `СБРОСИТЬ` активирует красную кнопку «Удалить выбранное (N)» (на `--mg-status-danger-solid`, задизейблена пока слово не введено и/или N=0).
- **Финальная модалка** подтверждения: перечисляет выбранные категории с корректным склонением («3 категории» / «4 категории»), затем тост об успехе.

## 11. Поведение и состояния

- **Тема**: тумблер в шапке и карточки на вкладке «Внешний вид» переключают класс `.dark` на корневом `.surface`. Все цвета — через токены, поэтому обе темы работают без дублирования стилей. Проверить контраст в navy-теме (бренд ремапится на `#4C7DF0`).
- **Навигация**: клик по пункту рельса меняет активный раздел и сбрасывает под-вкладку профиля на «Профиль». Поиск фильтрует пункты по лейблу.
- **Все таблицы** (Пользователи, Справочники, Журнал) обёрнуты в контейнер `overflow-x:auto` с `min-width` — на узком контейнере колонки **прокручиваются**, а не режутся и не ломают layout. Сохранить это при переносе.
- **Режим правки** (Пользователи, Справочники): кнопка «Редактировать» — тоггл, показывающий/скрывающий колонку «Действия».
- **Модалки**: закрытие по оверлею и крестику; `stopPropagation` на теле.
- **Тосты**: появляются при успешных действиях (сохранение, подключение, сброс), автоскрытие.
- **Адаптив**: экран рассчитан на десктоп CRM. Мин. рабочая ширина контента ~820–860px (за счёт скролла таблиц). Рельс фиксирован 264px.

## 13. Что важно при реализации

1. **Только токены `--mg-*`** для цветов/радиусов/теней/шрифтов — никаких сырых hex. Локальные `--c-*` замапить на нейтрали вашей системы.
2. **PrimeReact + PrimeIcons** — использовать готовые компоненты (Dialog, Dropdown, InputText, InputSwitch, DataTable) вместо ручной вёрстки, сохраняя визуал прототипа.
3. **Обе темы** должны работать через переключение класса, а не через отдельные стили.
4. **Горизонтальный скролл таблиц** обязателен — это защита от «расползания» на узком контейнере.
5. Тексты/копирайт брать из прототипа как есть (русскоязычный интерфейс).
