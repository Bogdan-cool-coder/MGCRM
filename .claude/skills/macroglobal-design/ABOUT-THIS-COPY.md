# О содержимом `skills/macroglobal-design/`

Это дизайн-система MACRO Global CRM — **источник правды по визуалу** для Claude Code.

## Что здесь есть
- `styles.css` + `tokens/` — **каноничные значения** (цвета, типографика, спейсинг, радиусы,
  тени, семантика, **тёмная тема** `dark.css`, base-слой, логические свойства). Это главное.
- `components/**/*.prompt.md` — **контракты компонентов**: пропсы, варианты, состояния,
  правила использования. Реализуй по ним.
- `components/**/*.card.html` — визуальные карточки-референсы разметки/классов.
- `guidelines/` — специмены (цвета, типографика, спейсинг, бренд, тёмная тема, RTL).
- `ui_kits/crm/` — сборные экраны-референсы (index.html).
- `readme.md` · `SKILL.md` · `README-DARK-THEME.md` — решения, критика, гайд по тёмной теме.

## Чего здесь намеренно НЕТ
React-исходники компонентов (`*.jsx` / `*.d.ts`) в эту handoff-копию **не включены**: они
рендерятся в OpenMind-превью на React, а целевой репозиторий MGCRM — **Vue + PrimeVue**.
Для реализации нужны не React-исходники, а **токены** (`tokens/*.css`) и **контракты**
(`*.prompt.md`) — по ним строится Vue-компонент на существующих PrimeVue-примитивах.

> Живые React-исходники остаются в OpenMind-проекте дизайн-системы (там же, где
> генерируется эта система) — если понадобятся как референс поведения, возьми их оттуда.
